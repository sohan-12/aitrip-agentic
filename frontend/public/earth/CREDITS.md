# Earth imagery

The daytime map uses NASA Blue Marble imagery. The nighttime map shows illuminated land at night. Both equirectangular images are distributed in the three-globe example assets by Vasco Asturiano. AITrip resizes and re-encodes these maps locally. The fallback view is an orthographic projection of the same two images, shaded and composited specifically for this project.

- [Daytime map in three-globe](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-blue-marble.jpg)
- [Nighttime map in three-globe](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-night.jpg)
- [NASA Blue Marble](https://science.nasa.gov/resource/blue-marble/)
